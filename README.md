# java-calculator-precourse

# 🧩 구현할 기능 목록

### 📥 입력

- "덧셈할 문자열을 입력해 주세요."를 출력한다.
    - 사용자에게 문자열(String type)을 입력받는다.
        - default 구분자를 사용한 경우
        - custom 구분자를 사용한 경우
        - 잘못된 값을 입력할 경우
    - 세가지 경우 중 어떤 경우인지 판단한다.

### 🛠️ 기능

- default 구분자를 사용한 경우
    - 문자열에서 숫자를 추출한다.
    - 문자열의 type을 변경한다.
    - 숫자들의 합을 구한다.
- custom 구분자를 사용한 경우
    - custom 구분자를 추출한다.
    - 문자열에서 숫자를 추출한다.
    - 문자열의 type을 변경한다.
    - 숫자들의 합을 구한다.
- 잘못된 값을 입력한 경우
    - 사용자가 쉼표나 콜론을 custom 구분자로 입력했을 때 `IllegalArgumentException`을 발생시킨다.
    - 사용자가 구분자 이외의 문자를 입력했을 때 `IllegalArgumentException`을 발생시킨다.
    - 사용자가 입력한 숫자가 범위를 벗어날 때 `IllegalArgumentException`을 발생시킨다.
    - 커스텀 구분자를 올바른 형식으로 입력하지 않았을 때 `IllegalArgumentException`을 발생시킨다.
    - 양수가 아닌 음수가 입력에 포함되었을 때 `IllegalArgumentException`을 발생시킨다.

### 📤 출력

- "결과: "와 숫자 합을 출력한다.

### ✅ 구분자 경우의 수 체크리스트

- [ ] 구분자로 공백이 올 수 있다.
- [ ] 구분자로 숫자가 올 수 있다.
- [ ] 구분자로 연속된 문자가 올 수 있다.
- [ ] 구분자가 연속해서 입력되면 0으로 처리한다.
- [ ] 구분자가 빈 문자열이면 모든 수를 더한다.
- [ ] 구분자로 '.'이 주어지면, 모든 수를 정수로 처리한다.
