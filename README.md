# java-calculator-precourse

# 구현할 기능 목록

- 입력
    - "덧셈할 문자열을 입력해 주세요."를 출력한다.
        - 사용자에게 문자열(String type)을 입력받는다.
            - default 구분자를 사용한 경우
            - custom 구분자를 사용한 경우
            - 잘못된 값을 입력할 경우
    - 세가지 경우 중 어떤 경우인지 판단한다.
- default 구분자를 사용한 경우
    - 문자열에서 숫자를 추출한다.
    - 숫자들의 합을 구한다.
- custom 구분자를 사용한 경우
    - custom 구분자를 추출한다.
    - 문자열에서 숫자를 추출한다.
    - 숫자들의 합을 구한다.
- 잘못된 값을 입력한 경우
    - 사용자가 쉼표나 콜론을 custom 구분자로 입력했을 때
- 출력
    - "결과: "와 숫자 합을 출력한다.
